# 本机配置快照摘要

项目基于 2026-07-15 的本机 Mihomo 配置备份及 2026-07-17 的运行状态整理。

## 保留的设计

- Mihomo Meta v1.19.28，Linux amd64；
- mixed port `7890`；
- Controller 仅监听 `127.0.0.1:9090`；
- rule 模式、fake-ip DNS、国内公共 DNS 与 DoH fallback；
- `mihomo` 独立用户、`UMask=0077` 和 systemd 沙箱加固；
- 终端级代理开关、PID 启动时间校验和文件锁；
- 交互式两级 Selector 选择；
- 带测试、备份和回滚的订阅管理。

## 未提交的本机数据

备份中有 69 个真实节点：17 个 AnyTLS、42 个 VLESS、10 个 Hysteria2。另有 3 个策略组和 514 条路由规则。节点名称、服务器、端口、UUID、密码、传输参数以及完整的个性化域名规则均未进入仓库。

## 有意调整

本机备份使用 `allow-lan: true` 和 `bind-address: '*'`。仓库模板改为 `allow-lan: false` 与 `127.0.0.1`，避免新安装默认把代理端口暴露到局域网。确需 LAN 访问时，应同时配置主机防火墙和可信网段后再手工开启。

原配置的 514 条规则被最小化为私网网段直连与 `MATCH,默认代理`，DNS fallback 的 GeoIP 过滤也在模板中关闭。模板不依赖 GeoIP 数据库，因此首次配置测试不会在尚无可用代理时尝试下载 MMDB；这也避免泄露个人使用模式并让模板更容易审计。
